## 一、游戏总览

- 玩家领养一名侠士（选门派），维持其**体力**与**心情**，通过打本、修练积累**修为**晋升称号，赚**金币**买吃穿、升级家园。
- 硬件：ESP32-C3 Super Mini + 1.44寸 ST7735 128×128 彩屏 + 4 按键（▲▼AB）+ 无源蜂鸣器 + 锂电池。

### 核心循环
```
喂食/打坐（消耗金币）→ 维持体力心情 → 打木桩/下副本（消耗体力）
        → 得修为+金币 → 晋升称号 / 升级家园 → 解锁更好装备的物品 → 循环
```

### 异常状态链
```
正常 →(随机/挖宝)→ 脏乱 mess(0~3) → 需打扫
正常 →(随机)→ 中毒 poisoned →(3游戏小时不解)→ 重伤 down → 需玉露丸（或静养自愈）
```

> **重要：异常状态不封锁行动。** v7.0 及以前中毒/重伤会禁止一切操作，而解毒只能靠 200 金的玉露丸——没药没钱就再也赚不到钱，状态永远清不掉，等同坏档。v7.1 起改为「照常干活，收益打折」：
> - 中毒：所有产出（修为 / 金币 / 副本掉落率 / 赌坊赔付）**×0.8（-20%）**
> - 重伤：同上 **×0.6（-40%）**
> - 属性恢复（吃饭回体力、打坐回心情）**不打折**，否则同样会陷入恢复不动的死循环
> - 重伤自愈：体力与心情都 ≥60 并维持 2 游戏小时，伤势自然痊愈（不依赖药品）
```

### 背包 / 商城 = 列表页 + 详情页 两段式

### 小游戏 · 黑市赌坊（押大小）✅
- 规则：三颗骰子，点数 11+ 为**大**、10 以下为**小**，**三同豹子庄家通吃**。
- 流程：▲▼ 押大/小 → A 进注额 → ▲▼ 调注（50/100/200/500/1000，上限=身上金币）→ A 开骰（约 1 秒摇动动画）。
- 赔付：押中 1:1 返还 + 修为+2；押中后 A 再来一局，B 离开。
- 限制：进入需金币 ≥50；输光（<50 金）自动请出赌坊；异常状态（中毒/重伤）**可以进**，但赢来的金币按收益系数打折（×0.8 / ×0.6）。

## 七、副本 ✅

- **入口**：日常页带「本」标记的条目（大战/阵营战场/秘境日常/团本周本），A 键进入。
- **前置**：体力≥30，出本冷却 60s。
- **消耗**：体力-12，心情-6。**战斗时长**：10s（原型演示值，固件建议改为 3~10 现实分钟）。

### 结算 ✅
| 结果 | 概率公式 | 收益 | 失败 |
|---|---|---|---|
| 通关 | min(90%, 40% + 修为/500 + 体力/300) | 固定掉落 + 额外掉落（按各副本掉落表） | 心情-10，修为+5，无物品掉落 |

### 掉落结构 ✅ 结构已定（数值为建议值，可调）

**两层掉落体系**：
1. **固定掉落**：通关**必得**的基础收益（金币 + 修为，区间随机）。
2. **额外掉落**：通关后对掉落表中**每件物品独立掷骰**，命中就进包——可以一件不掉（纯保底），也可以多件齐掉；每件物品掉率互不影响、互不占用。
3. 失败无额外掉落，只给安慰修为+5（已有 ✅）。
4. 稀有度参考：白 > 绿 > 蓝 > 紫，掉率建议量级 50% / 20% / 8% / ≤3%。
