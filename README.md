# 剑网三拓麻歌子 · JX3 Tamagotchi

一个剑网三主题的电子宠物（拓麻歌子）项目：玩家领养一名侠士，选门派（纯阳 / 天策 / 七秀 / 少林），维持体力与心情，通过打坐、打木桩、挖宝、下副本积累修为晋升称号，赚金币买吃穿、升级家园。

**线上试玩**：<https://syabin.github.io/jx3-tamagotchi/>

## 项目定位

- **网页原型先行**：单文件 `index.html` 实现完整游戏，既是可玩的 Demo，也是未来 ESP32 固件的"设计蓝图"。
- **单一事实来源**：所有数值以 `web端设计/设定集.md`（GDD）为准 —— 改数值先改设定集，再同步代码。
- **目标硬件**：ESP32-C3 Super Mini + 1.44 寸 ST7735 128×128 彩屏 + 4 按键（▲▼ A B）+ 无源蜂鸣器 + 锂电池。

## 玩法速览

- **核心循环**：喂食/打坐（消耗金币）→ 维持体力心情 → 打木桩/下副本（消耗体力）→ 得修为+金币 → 晋升称号 / 升级家园 → 循环。
- **主界面布局（v0.2.0 重构）**：底部仅一排 4 个按钮（**活动 / 游戏 / 背包 / 商城**），▲▼（←→ 同效）左右循环选中，图标不带文字；上方空间全部让给场景——顶部一条状态栏（称号·门派/金币 + 体/心/修），中央大场景**重绘背景**（远山剪影、慢云、太阳/弯月与星、草沿泥地、篱笆草丛）+ **人物放大居中**（银发星星眼 Q 版角色 s=3）；选中模块的名称与说明只在切换后显示 2 秒随即消失（toast 优先覆盖，平时长条空白——贴近正版拓麻歌子的做法）。设置不占图标位，长按 B 呼出；主页按 B 进手札、再按 B 返回。
- **活动页**（原日常页扩展）：上半是侠士行动（**打坐/木桩/挖宝/家园**，A 直接执行，冷却中标注），下半是今日剑网三日常（带「本」标记条目 A 进副本）。
- **游戏厅**（v0.2.0 新增）：进入后 ◀▶ 左右选游戏，A 进入所选——**押大小**（黑市赌坊）/ **打地鼠**（◀▶ 移锤 A 敲，10 只一轮）/ **钓鱼**（时机条 A 收竿，3 杆结算）/ **翻牌配对**（6 张 3 对，全配大奖）；打地鼠/钓鱼/翻牌有独立冷却防刷。
- **异常状态不封锁行动**（v7.1 重要设计）：中毒所有产出 ×0.8、重伤 ×0.6 —— 只打折收益、不打折属性恢复，避免"没药没钱=坏档"的死锁；重伤时体力心情 ≥60 维持 2 游戏小时可自愈。
- **时间流速**：v8.2 起默认**真实 ×1**（原先 ×60）；面板可切 ×60 / ×600 / 真机档 ×10；离线最多结算 4 游戏小时。
- **副本掉落**：固定掉落（必得金币+修为）+ 额外掉落（掉落表内每件物品独立掷骰），四本差异化，经济锚点为大战固定掉落 250 金。
- **五大养成系统（v7.6）**：
  - 🗡️ **装备系统**（代替拓麻歌子的进化分支）：武器/护身/饰品三槽位穿戴，精铁剑木桩修为+50%、平安符副本胜率+15% 等，同槽换装互斥；
  - 🌙 **昼夜作息**：游戏日从辰时（8 点）起算，22~6 时侠士自动就寝（消耗大减、恶事件免疫、行动受限，天亮自动起床）；
  - 🏮 **庭院装饰**：盆栽/屏风/长明灯购入即布置家园庭院，提供常驻流失减免；
  - 🧚 **保姆代管**：家园页 100 金雇 8 游戏时辰，代管起居、自动洒扫、离线也生效；
  - 📅 **每日登录奖励**：现实自然日计，连续登录 50→200 金递增 + 包子，断签重置；**30% 概率「鸿运当头」额外赠一件装备**（与商城同池，按品级加权，凡品常见、珍品稀有）。
- **品级与稀有掉落（v7.7）**：装备分**凡品/良品/珍品**三品级（列表按品级着色，详情页标注）；团本周本 **0.1% 概率掉落橙色玄晶**——不同赛季不同玄晶，本赛季为**铸天玄晶**（可卖 2500 金）。
- **商城/背包分类展示**：全部 / 食品 / 丹药 / 装备 / 家具 / 材料六个分类页签。**两级导航（v8.1）**：进入页面先选中分类栏（▲▼ 换分类，选中项常亮不闪、列表不高亮）→ A 进入列表 → B 退回分类栏 → 再 B 回主页。

## 功能特性

- 🎮 像素小人程序化动画、昼夜/家园场景、使用物品整页演出动画；图标参考剑网3无界版游戏内配色像素重绘（暗色圆牌+金环+金色纹样）；开机页「剑网三 / 剑侠情缘·单机版3」
- 📅 日常页对接 [jx3api](https://www.jx3api.com) 活动日历（大战/阵营战场/秘境/团本等，带"本"标记可直接进副本）
- 📡 **双通道取数**（v7.3，0.1.87 路径改为 `web端设计/data/daily.json`）：网页端读 GitHub Actions 每小时预取的同源 JSON（零跨域、零代理、零服务器）；该文件不存在时（ESP32 主机端）自动直连 jx3api。不用任何公共 CORS 代理。
- 💾 localStorage 存档（`jx3tama`）+ 离线结算，旧档自动补新字段默认值
- 📶 设置页含 OTA 检查（读 `web端设计/version.json` 比对版本号）、WiFi/热点（固件蓝图）、**音效开关**（v8.2，与面板「静音」共用偏好并持久化）、真机预览（锁 30fps + 屏幕轻微提亮；v8.5 撤销 v8.4 暖屏色域映射，v8.6 连机身边框/按键的暖灰覆盖也去掉，金框粉键始终明亮）；区服设置已移除（jx3api 日历按全服返回，无实际作用）
- ⚙️ **随时呼出设置**（v8.0，v8.2 起为唯一入口）：**长按 B 键（键盘 B/Esc 或实体按钮）1.5 秒**（v8.3 由 500ms 调长防误触）从任意页面打开系统设置，短按 B 仍是返回；主界面不再有设置按钮。设置页 B 返回时回到原页面（摇骰中、背包分类行等状态都保留）
- 📖 **手札返回**（v8.2）：主页短按 B 进「侠士手札」，手札页再按 B 返回主页；A 键在手札页不退出（与原提示一致）
- ⌨️ 全游戏可只用 ▲▼ A B 四键操作（对应真机按键），手机支持屏幕滑动选单；支持长按连续滚动

## 运行与部署

- **本地运行**：直接用浏览器打开 `index.html` 即可。日常数据走同源 `web端设计/data/daily.json`（本地打开 file:// 时读不到，会退到 localStorage 缓存）；ESP32 主机端自动直连 jx3api。
- **线上部署**：仓库推送 `main` 分支根目录，GitHub Pages 自动生效（当前线上版本 **0.2.0**）。CDN 缓存 `max-age=600`，更新后可加 `?t=时间戳` 强刷。
- **版本命名**：采用语义化三段式 `主.次.补丁`（如 `0.1.87`）。**上线前**主版本固定 `0`；次版本是功能版本，大功能 / 新系统更新时递增（如 `0.1.87` → `0.2.0`，进位后补丁归零）；补丁号用于小修小补。正式上线后再升 `1.0.0`。版本号由我按改动量自行调整。

### v7.2 · 日常数据改回运行时直连
- 用户要求「由网页/主机获取，不需要 json」。改造前实测：jx3api 不返回 `Access-Control-Allow-Origin`（OPTIONS/GET 均无），也不支持 JSONP（callback 被忽略），浏览器跨域直连必被拦。
- 改用 jx3api 直连并保留本地缓存兜底，删除 Actions 预取与 `data/daily.json`；如实告知后果：网页端当时拿不到新数据，ESP32 固件原生 HTTP 无跨域限制才可用。

### v7.3 · 代理问题的最终解
- 用户先问「代理应付一下」，后明确否决海外代理 `r.jina.ai`。公共代理复测全灭：allorigins/codetabs 超时、corsproxy.io 要 key、cors.lol 限流、whateverorigin 返回 HTML；r.jina.ai 虽能通但成功率仅 1/4 且为海外服务。
- 定稿**双通道**：网页端读同源 `data/daily.json`（Actions 每小时预取，走客户端网络，运行时不碰任何代理），ESP32/兜底直连 jx3api，全失败用 localStorage 缓存。恢复 workflow 与 json，线上三项验证通过。

### v8.3 · B 键二次触发修复
- 用户反馈「主页按 B 进不去手札、其他页按 B 反而能进、进了手札退不出」。根因：实体 B 键把 `pointerup`/`pointerleave`/`pointercancel` 三个事件都接到 `pressB()`，一次点击被当成两次返回（主页→手札→主页）。
- 修复：`pointerup` 作为唯一触发点，`pointerleave`/`pointercancel` 只清长按计时不返回；长按呼出设置阈值 `500ms→1.5 秒`（`B_HOLD_MS`）防误触。
