# 剑侠情缘·单机版三 · ESP32-C3 固件

与网页版 **0.2.12** 一比一：同一套 43 枚 16×16 精灵、同一套物品/称号/声望/活动/游戏数据表、同一套页面与按键逻辑。

> 2026-11-28：旧版固件（v8.x，8 格菜单 / 12px 逻辑坐标 / 独立跑马灯）整体删除，按网页 128×128 画布重写。旧存档（NVS magic 不同）会被自动忽略，首次上电开新档。

---

## 一、硬件与接线

| 屏幕丝印 | ESP32-C3 Super Mini |
|---|---|
| VCC | 3V3 |
| GND | GND |
| SCL | GPIO4 |
| SDA | GPIO6 |
| CS  | GPIO7 |
| DC  | GPIO10 |
| RES | GPIO3 |
| BLK | GPIO5 |

板载按键：K1(▲)→GPIO0 · K2(▼)→GPIO1 · K3(A)→GPIO20 · K4(B)→GPIO21。

GPIO2/8/9 是启动配置脚，不占用。GPIO20/21 同时是 UART0，固件里串口已显式不绑引脚，否则按键会被抢。

## 二、编译与烧录

Arduino IDE 1.8.19 + esp32 core 2.0.17：

```
arduino-builder -compile -fqbn=esp32:esp32:esp32c3 firmware.ino
esptool --chip esp32c3 --port COM5 write_flash -z \
  0x0     build/firmware.ino.bootloader.bin \
  0x8000  build/firmware.ino.partitions.bin \
  0xe000  <core>/tools/partitions/boot_app0.bin \
  0x10000 build/firmware.ino.bin
```

实测体积：**397 KB flash（30%）/ 15.6 KB RAM（4%）**。

| 键 | 作用 |

## 五、玩法数值（与网页一致）

- 体力/心情每秒按游戏小时衰减，就寝（22~6 时）消耗降到 0.35/0.2，保姆再降到 0.2。
- 中毒收益 ×0.8、重伤 ×0.6，**都不封锁行动**。
- 打坐 15 秒 CD、心情+20、修为+3（酒葫芦+2）；木桩 25 秒 CD、修为+12（精铁剑 ×1.5）；挖宝 30 秒 CD；副本 60 秒 CD、耗时 10 秒、体力门槛 30。
- 称号五阶：初闯江湖 / 江湖新秀 / 一方名侠 / 武林名宿 / 武林至尊；声望五阶：中立 / 友好 / 尊敬 / 崇敬 / 崇拜；家园五级：荒地 / 茅舍 / 宅院 / 别院 / 山庄。
- 每日登录按「游戏天」结算（每 24 游戏小时 = 1 天），50 金起步每连签 +25 封顶 200，附赠包子，30% 概率「鸿运当头」送装备。

## 六、目录

```
firmware.ino      setup/loop：1s 逻辑心跳 + 30fps 渲染 + 15s 存档
config.h          引脚、颜色、全部数据表与文案
game.h/.cpp       存档(NVS)与玩法逻辑
display.h/.cpp    帧缓存 + 点阵文字 + 精灵 + 陈月 + 稻香村 + 校色
ui.h/.cpp         11 个页面渲染与交互
input.cpp         4 键去抖/连发/长按
font_cn.h         自动生成：812 个 12×12 汉字
sprites.h         自动生成：43 枚 16×16 RGB565 精灵
boot_logo.h       开机 LOGO 48×48
tools/gen_font.py 扫源码里的中文重新生成字库
tools/gen_sprites.py 从网页 SPR 表生成 sprites.h
```

**改了中文文案后必须重跑** `python tools/gen_font.py`，否则新字会显示成空心框。

## 七、已知限制

- 手札「游戏日常」需要联网拉 jx3api，固件暂未接网络，页面显示提示文字；「开服查询」为预留页。
- WiFi / 热点 / 系统升级在固件里是占位交互（无凭据时不发起连接）。
- 邮箱只保留最近 8 封（网页 30 封），存档体积考虑。
