# 剑网三拓麻歌子 · ESP32-C3 实体机固件

一套可直接烧录的 Arduino 固件，对应网页版 **v0.2.10 / 固件 v8.4** 的核心玩法。
硬件：**ESP32-C3 Super Mini + 1.44 英寸 128×128 ST7735S 彩屏模块（板载 K1–K4 四键）**。

---

## 一、接线（先接线，再上电）

你这块屏的丝印从左到右是：

```
K1  K2  K3  K4  BLK  CS  DC  RES  SDA  SCL  VCC  GND
▲   ▼   A   B   背光 片选 命令 复位 数据 时钟 电源 地
```

### 逐针接线表

| 屏幕丝印 | 接到 ESP32-C3 Super Mini | 说明 |
|---|---|---|
| **VCC** | **3V3** | ⚠️ 只能 3.3V，接 5V 会烧屏 |
| **GND** | **GND** | 必须共地 |
| **SCL** | **GPIO4** | SPI 时钟 |
| **SDA** | **GPIO6** | SPI 数据（MOSI） |
| **CS** | **GPIO7** | 片选 |
| **DC** | **GPIO10** | 数据/命令选择 |
| **RES** | **GPIO3** | 复位 |
| **BLK** | **GPIO5** | 背光，高电平点亮 |
| **K1** | **GPIO0** | ▲ 上选 |
| **K2** | **GPIO1** | ▼ 下选 |
| **K3** | **GPIO20** | A 确认 |
| **K4** | **GPIO21** | B 返回 |

### 三条硬性规则

1. **GPIO2 / GPIO8 / GPIO9 绝对不要接。** 这三根是 ESP32-C3 的启动配置脚，接了可能导致芯片进不了下载模式或反复重启。
2. **VCC 接 3V3，不接 5V。** 屏幕模块大多只支持 3.3V。
3. **先断电接线，检查一遍再插 USB。** 接错电源脚最容易烧。

### C3 Super Mini 引脚位置

把板子平放，**USB-C 在上、芯片面朝你**。两排引脚从上往下依次是：

```
   左排（USB 左侧）          右排（USB 右侧）
   5   ← BLK 背光            5V   ✕ 不用
   6   ← SDA 数据            GND  ← GND
   7   ← CS  片选            3V3  ← VCC 电源
   8   ✕ 启动脚，别接         4    ← SCL 时钟
   9   ✕ 启动脚，别接         3    ← RES 复位
   10  ← DC  命令            2    ✕ 启动脚，别接
   20  ← K3  确认(A)          1    ← K2  下选(▼)
   21  ← K4  返回(B)          0    ← K1  上选(▲)
```

丝印数字就是 GPIO 号，无需换算。板载蓝色 LED 在 GPIO8（低电平亮），BOOT 键接 GPIO9——这也是不能占用它们的原因。

> ⚠️ 市面 Super Mini 有多个版本，**个别 clone 左右排顺序相反**。上电前一定拿板子实物核对丝印数字，以你手上这块为准；接错电源脚会烧。

### 屏幕模块引脚位置

屏幕顶边一排 12 针，从左到右丝印：

```
K1   K2   K3   K4   BLK  CS   DC   RES  SDA  SCL  VCC  GND
▲    ▼    A    B    背光 片选 命令 复位 数据 时钟 电源 地
│    │    │    │     │    │    │    │    │    │    │    │
GPIO0 GPIO1 GPIO20 GPIO21 GPIO5 GPIO7 GPIO10 GPIO3 GPIO6 GPIO4 3V3 GND
```

完整的彩色接线图见同目录 `wiring.svg`——**两端引脚都画出、12 根线逐一对应**，浏览器打开可对着板子逐根核对。图里屏幕针脚按接线顺序排列，实物丝印顺序见图和上表。

> 你的屏幕模块自带 4 个轻触按键，K1–K4 就是它们的引线。按下按键时对应引脚被拉低，代码里已配置为内部上拉，不需要外接电阻。

## 二、安装与烧录（Arduino IDE，推荐）

### 0. 国内镜像（下载慢/失败时必看）

默认的 `raw.githubusercontent.com` 和 `espressif.github.io` 在国内经常超时。
**乐鑫官方的极狐 GitLab 镜像**最稳，索引里的工具链地址已全部改写为 `dl.espressif.cn`，实测 243MB 核心包 2 秒下完。

菜单 **文件 → 首选项 → 附加开发板管理器网址**，把默认网址**替换**为：

```
https://jihulab.com/esp-mirror/espressif/arduino-esp32/-/raw/gh-pages/package_esp32_index_cn.json
```

> 备选镜像：`https://arduino.me/packages/esp32.json`（可用但慢，约 18 秒才返回索引）。
> 清华 TUNA 的 `mirrors.tuna.tsinghua.edu.cn/arduino/package_esp32_index.json` **已失效（404）**，不要再用。
> 换源后若仍用旧索引，退出 IDE，删除 `%LOCALAPPDATA%\Arduino15\cache` 和 `staging` 再打开。

三个 Adafruit 库也可从 Arduino 官方 CDN 直接下载 `.zip`，在 IDE 里用
**项目 → 加载库 → 添加 .ZIP 库** 导入（无需走库管理器）：

| 库 | 版本 | 直链 |
|---|---|---|
| Adafruit GFX Library | 2.0.0 | `https://downloads.arduino.cc/libraries/github.com/adafruit/Adafruit_GFX_Library-2.0.0.zip` |
| Adafruit ST7735 and ST7789 Library | 1.9.3 | `https://downloads.arduino.cc/libraries/github.com/adafruit/Adafruit_ST7735_and_ST7789_Library-1.9.3.zip` |
| Adafruit BusIO（依赖） | 1.9.9 | `https://downloads.arduino.cc/libraries/github.com/adafruit/Adafruit_BusIO-1.9.9.zip` |

> 本机（Windows）已完成上述全部配置：IDE 1.8.19 在 `桌面\arduino-1.8.19`，
> 三个库已放入其 `libraries\`，ESP32 2.0.17-cn 核心与全套工具链已装入
> `%LOCALAPPDATA%\Arduino15\packages\esp32\`，并已用真实编译验证通过。

### 1. 安装开发环境

1. 下载并安装 Arduino IDE（本机为 1.8.19，2.x 同样适用）。
2. 按上面第 0 步设置镜像网址。
3. **工具 → 开发板 → 开发板管理器**，搜索 `esp32`，安装 **Espressif Systems** 的 **2.0.17** 版本
   （本机已装好，不用重装；3.x 未在本机验证，建议沿用 2.0.17）。

### 2. 安装显示库

本机已装好三个库（GFX 2.0.0 / ST7735 1.9.3 / BusIO 1.9.9），可跳过此步。
换机器时按上面第 0 步的直链下载 `.zip` 导入，或走库管理器安装。

### 3. 打开工程

用 Arduino IDE 打开 `firmware` 文件夹（里面必须有 `firmware.ino`，已经放好了）。

### 4. 板子设置

| 项目 | 选择 |
|---|---|
| 开发板 | `ESP32C3 Dev Module` |
| Upload Speed | `921600` |
| USB CDC On Boot | `Enabled`（若 USB 口是原生 USB） |
| Flash Size | `4MB (FS:2MB OTA:~1019KB)` |
| Partition Scheme | `Default 4MB with spiffs` |
| Port | 选你的 COM 口 |

> 如果端口列表里看不到板子，按住板上的 **BOOT** 键再插 USB，选择出现的 USB 串口。

### 5. 编译上传

点右上角 **→（上传）**。首次编译约 1–3 分钟。看到 `Hard resetting via RTS pin` 即完成。

### 6. 可选：填 WiFi 获取准确时间

把 `wifi_credentials.example.h` 复制为 `wifi_credentials.h`，填入你家 WiFi：

```cpp
#define WIFI_SSID "你的WiFi名"
#define WIFI_PASS "你的密码"
```

不填也能完整游玩，只是昼夜与每日签到以编译时间为基准。`wifi_credentials.h` 不要传到公开仓库。

## 三、操作方式

| 按键 | 短按 | 长按 |
|---|---|---|
| **▲ (K1)** | 上移选中 | **3 秒：切换屏幕色彩模式（4 档循环）** |
| **▼ (K2)** | 下移选中 | 0.48 秒后连续滚动 |
| **A (K3)** | 确认 / 进入 / 使用 | — |
| **B (K4)** | 返回；主页短按进「侠士手札」 | **1.5 秒：从任意页呼出系统设置** |

> **如果屏幕颜色发绿、发青、发白（像开了反色）**：在任意页面按住 **▲ 3 秒**，
> 屏幕会依次切换 `BGR → RGB → BGR INV → RGB INV` 四种色序/反显组合，
> 右下角会弹出当前模式名。找到颜色正常的那一档松手即可，**自动存进 NVS，掉电不丢**。
> 出厂默认是 `RGB`（大多数 1.44" ST7735S 模块用这一档）。

流程：开机画面 → 按 A → 选门派（纯阳 / 天策 / 七秀 / 少林）→ 按 A 进入主页。

主页上面 4 个图标：日常 / 背包 / 商城 / 打坐；下面 4 个：木桩 / 挖宝 / 小游戏 / 家园。
左侧是常驻状态面板，中间是侠士，背景会随昼夜变化。

### 与网页版的三处已知差异

1. **日常页显示 5 个固定副本入口**，不抓取 jx3api 实时活动文字（固件可以联网，但 128×128 屏幕放不下长活动名，入口本身一致）。
2. **副本是即时结算**，没有网页版 10 秒读条动画（真机上省电、也避免黑屏卡住）；成本与掉落一致。
3. **OTA 在线升级未实现**（需要分区与签名，烧错会变砖）。要升级请重新编译烧录。

## 五、排错

| 现象 | 原因 / 处理 |
|---|---|
| 屏幕全黑 | 先量 VCC 是否 3.3V；确认 BLK 接 GPIO5。若你的模块背光是**低电平亮**，把 `display.cpp` 的 `digitalWrite(PIN_BLK, HIGH)` 改成 `LOW` |
| **整屏发绿 / 发青 / 反白** | 色序或反显设置不对。**按住 ▲ 3 秒切换模式**，四档里总有一个正常，自动记忆。也可改 `config.h` 的 `DISP_MODE_DEFAULT`（0=BGR，1=RGB，2=BGR反显，3=RGB反显） |
| **画面不停滚动 / 撕裂 / 从上往下刷** | 已彻底修复：现在所有绘制先写进 32KB 整帧缓存，再一次性推屏。若仍出现，把 `config.h` 的 `SPI_HZ` 从 40MHz 降到 27000000 或 20000000 |
| 画面整体偏出几个像素 / 边缘有杂色 | 改 `config.h` 的 `DISP_OFF_X` / `DISP_OFF_Y`（1.44" 绿标默认 2/1），每次 ±1 调整 |
| 画面颜色偏红/偏蓝、内容偏移 | 屏驱动初始化参数不对。把 `display.cpp` 里 `tft.initR(INITR_144GREENTAB)` 改成 `INITR_BLACKTAB` |
| **`No DFU capable USB device available`** | **板型选成了 `Arduino Nano ESP32`（nano_nora），它的上传工具是 `dfu-util`。** 改选 **工具 → 开发板 → esp32 → ESP32C3 Dev Module**，端口选 COMx 即可 |
| 上传失败 / 找不到端口 | 按住 BOOT 再插 USB；装 CH340/CP2102 驱动；确认选的是 C3 的开发板 |
| 端口列表里只有 COM5 且名字是「USB 串行设备」 | 这是对的，C3 走原生 USB（VID_303A/PID_1001）。不需要 CH340 驱动 |
| 上传成功但立刻重启循环 | 检查是否误接了 GPIO2 / GPIO8 / GPIO9 |
| 按键无反应 | K1–K4 按下应为低电平；确认接的是 GPIO0/1/20/21。**注意 GPIO20/21 是 C3 的 UART0 引脚，固件已显式把 Serial 绑到 -1 避开，不要自行改回 `Serial.begin(115200)`** |
| 中文显示成方块 | 改过文案后没重新生成字库：运行 `python tools/gen_font.py`，重新编译 |
| 存档丢失 | 存档写在 NVS；清档会覆盖。断电不会丢，但重新烧录不会清除 |

## 六、文件说明

```
firmware/
├── firmware.ino              # Arduino IDE 入口
├── main.cpp                  # setup / loop

├── game.h / game.cpp         # 状态机、存档、数值、装备/昼夜/保姆/签到/副本/赌坊
├── display.h / display.cpp   # ST7735S 驱动、点阵字、图标、像素小人、场景
├── ui.h / ui.cpp             # 11 个页面的布局与渲染
├── input.h / input.cpp       # 四键状态机与全页面导航
├── net.h / net.cpp           # 可选 WiFi + NTP 校时
├── font_cn.h                 # 自动生成的 12×12 点阵字库（781 字形）
├── tools/gen_font.py         # 字库生成脚本（Pillow）
├── tools/check.py            # 轻量静态检查
├── platformio.ini            # PlatformIO 配置（可选）
└── wifi_credentials.example.h
```

**改中文文案后**：运行 `python tools/gen_font.py`，再重新编译。
**改数值后**：同时改 `config.h` 与网页仓的 `design/设定集.md`，保持单一事实来源。
